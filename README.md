# Titanic_Survival_Prediction

📌 Overview
A Machine Learning project that predicts whether a passenger survived the RMS Titanic disaster based on features like age, gender, class, and more.

🚀 Features
Predict survival (0 = No, 1 = Yes)
Data preprocessing (missing values, encoding)
Logistic Regression model
Accuracy evaluation
